
# AIRUUN Commercial Options
## ทางเลือกในการเสนอให้ลูกค้า

เอกสารนี้สรุปทางเลือกในการเสนอราคา AIRUUN แยกตามระดับการลงทุน ขอบเขตระบบ และความพร้อมในการต่อยอดในอนาคต

> ราคาทั้งหมดไม่รวม VAT 7%, Cloud Infrastructure, Third-party Licenses, Content Production และค่าใช้จ่ายจาก External Vendors

---

# Pricing Overview

| Option | Scope | Implementation | MA / Year | Webmaster / Year | Total Year 1 |
|---|---|---:|---:|---:|---:|
| **Option 1 — Launch First** | Phase 1 | 1,450,000 บาท | 150,000 บาท | 300,000 บาท | **1,900,000 บาท** |

# Option 1 — Launch First

## Investment

- **Implementation:** 1,450,000 บาท
- **Annual Maintenance Agreement:** 150,000 บาท/ปี
- **Webmaster Starter:** 25,000 บาท/เดือน
- **Webmaster Annual Fee:** 300,000 บาท/ปี

> **Total Year 1 Investment: 1,900,000 บาท**

## Objective

เปิดตัว AIRUUN เวอร์ชันแรกสำหรับ Pilot Audience โดยเน้น Brand Experience, Content Platform และการเก็บข้อมูล Engagement ขั้นพื้นฐาน

## Included Scope

- Product discovery และ requirement workshop
- User journey และ sitemap
- Responsive UX/UI design
- Basic design system
- AIRUUN brand experience
- Guest และ Member journey
- Basic member authentication
- Wellbeing onboarding
- 5 Wellbeing Pillars
- Founding, Heritage และ Documentary content
- The Dawn Thread
- Article, video, audio และ activity content types
- Custom CMS
- Content taxonomy และ tagging
- Basic admin roles
- Event listing
- Basic registration form
- GA4 และ standard event tracking
- PDPA consent interface
- QA, UAT และ production deployment
- Admin training
- Warranty 60–90 วัน

## Key Limitations

- Integration ไม่เกิน 1 จุด
- ยังไม่มี Member Profile แบบเต็ม
- ยังไม่มี Saved Content
- ยังไม่มี Advanced Personalization
- ยังไม่มี CRM/CDP Integration
- ยังไม่มี Custom Dashboard
- ยังไม่มี Full Community Module
- ยังไม่มี AI Recommendation

## Best For

- เริ่มต้นด้วย Pilot Audience
- ทดสอบความสนใจและพฤติกรรมผู้ใช้
- ลดความเสี่ยงก่อนลงทุนในระบบเต็ม
- ต้องการ Launch Platform ให้เร็วและควบคุมงบประมาณ

# Option 2 — Engagement Platform

## Recommended Option

## Investment

- **Phase 1:** 1,450,000 บาท
- **Phase 2:** 1,050,000 บาท
- **Total Implementation:** 2,500,000 บาท
- **Annual Maintenance Agreement:** 150,000 บาท/ปี
- **Webmaster Starter:** 25,000 บาท/เดือน
- **Webmaster Annual Fee:** 300,000 บาท/ปี

> **Total Year 1 Investment: 2,950,000 บาท**

## Objective

พัฒนา AIRUUN จาก Content Platform ให้เป็น Member Engagement Platform ที่สามารถสร้าง Personalized Experience และวัดผลเชิงธุรกิจได้

## Included Scope

รวม Scope ทั้งหมดจาก Option 1 และเพิ่ม:

- Member profile
- Preference management
- Saved content และ favorites
- Personalized homepage
- Rule-based content recommendation
- Recommendation ตาม Wellbeing Pillar
- Behavioral tracking
- Content viewed tracking
- Content completion tracking
- Content saved และ shared tracking
- Event registration tracking
- Advanced event registration
- Event capacity management
- Booking confirmation
- Cancellation workflow
- Reminder-ready workflow
- Member story submission
- Curated community workflow
- Admin review และ approval workflow
- Multi-role CMS workflow
- Return visit tracking
- Content performance reporting
- Event conversion reporting
- LINE Login หรือ Personalized Entry หนึ่งรูปแบบ
- Performance optimization
- UAT และ release support

## Business Value

ตัวเลือกนี้ช่วยให้ TGH เริ่มวิเคราะห์ได้ว่า:

- สมาชิกสนใจ Wellbeing Pillar ใด
- Content ประเภทใดสร้าง Engagement
- Content ใดทำให้ผู้ใช้กลับมาใช้งาน
- กิจกรรมใดมี Conversion สูง
- Member Segment ใดมีแนวโน้ม Active
- ควรนำเสนอ Content อะไรให้สมาชิกแต่ละกลุ่ม

## Best For

- ต้องการพิสูจน์ Business Value ของ AIRUUN
- ต้องการสร้าง Engagement มากกว่าการเผยแพร่ Content
- ต้องการเริ่ม Personalization โดยยังไม่ลงทุน AI เต็มรูปแบบ
- ต้องการเก็บ Behavioral Data สำหรับ Phase ต่อไป

> **TWF Recommendation:** Option 2 เป็นทางเลือกที่สมดุลที่สุดระหว่างงบประมาณ ความสามารถของ Platform และผลลัพธ์ทางธุรกิจ

# Option 3 — Full Platform Roadmap

## Investment

- **Phase 1:** 1,450,000 บาท
- **Phase 2:** 1,050,000 บาท
- **Phase 3:** 750,000 บาท
- **Total Implementation:** 3,250,000 บาท
- **Annual Maintenance Agreement:** 150,000 บาท/ปี
- **Webmaster Starter:** 25,000 บาท/เดือน
- **Webmaster Annual Fee:** 300,000 บาท/ปี

> **Total Year 1 Investment: 3,700,000 บาท**

## Objective

สร้าง AIRUUN ให้เป็น Platform Foundation ที่พร้อมรองรับ Enterprise Integration, Advanced Segmentation, CRM, LINE Ecosystem และ AI Recommendation ในอนาคต

## Included Scope

รวม Scope ทั้งหมดจาก Option 1 และ Option 2 และเพิ่ม:

- Audience segmentation structure
- Tier A–D readiness
- Member profile data schema
- Behavioral data schema
- Consent และ preference data structure
- CRM/CDP integration readiness
- Policyholder database integration readiness
- LINE OA และ Messaging API readiness
- Integration เพิ่มเติมไม่เกิน 1 ระบบ
- Custom engagement dashboard
- Member activation dashboard
- Segment performance dashboard
- Event performance dashboard
- Data export
- Admin reporting
- Basic audit log
- API documentation
- Solution architecture documentation
- Security review
- Performance and scalability review
- AI-ready content taxonomy
- AI recommendation architecture
- Future roadmap สำหรับ AI และ Community

## Business Value

- รองรับการขยายจาก Pilot ไปสู่ฐานสมาชิกขนาดใหญ่
- ลดความเสี่ยงจากการต้องรื้อ Architecture ภายหลัง
- เตรียมข้อมูลสำหรับ CRM Automation
- รองรับ Personalized LINE Communication
- เตรียมระบบสำหรับ AI Content Recommendation
- เชื่อมโยงข้อมูล Content, Member, Event และ Engagement
- สร้าง Marketing Insight สำหรับการวางแผนระยะยาว

## Best For

- ลูกค้าต้องการลงทุนระยะยาวตั้งแต่ Phase แรก
- มีความพร้อมด้าน Policyholder Data และ Integration
- ต้องการใช้ AIRUUN เป็น Strategic Member Platform
- ต้องการวาง Foundation สำหรับ CRM, LINE, Data และ AI

# Commercial Recommendation

## Recommended Proposal Positioning

เสนอ **Option 2 — Engagement Platform** เป็นทางเลือกหลัก เพราะสามารถสร้าง Member Engagement, Personalization และ Behavioral Insight ได้เพียงพอต่อการพิสูจน์ Business Value

ใช้ Option 1 เป็นทางเลือกสำหรับลูกค้าที่ต้องการเริ่มด้วย Pilot และจำกัดงบประมาณ

ใช้ Option 3 เป็น Full Roadmap สำหรับลูกค้าที่ต้องการวาง Enterprise Foundation ตั้งแต่ต้น

## Recommended Presentation Order

1. **Option 3 — Full Platform Roadmap**  
   แสดงภาพ Vision และศักยภาพสูงสุดของ AIRUUN

2. **Option 2 — Engagement Platform**  
   ระบุเป็น **Recommended Option**

3. **Option 1 — Launch First**  
   เป็นทางเลือก Controlled Pilot

## Negotiation Principle

> การลดราคา ควรเกิดจากการลดหรือเลื่อน Scope ไม่ใช่การลดราคาโดยคง Scope เดิมทั้งหมด

ตัวอย่าง Scope ที่สามารถเลื่อนไป Phase ถัดไป:

- Saved Content
- Member Story Submission
- Advanced Event Workflow
- Custom Dashboard
- Additional Integration
- Personalized Homepage
- Advanced Behavioral Reporting

# Client-facing Summary

> TWF proposes three implementation options for AIRUUN, ranging from a controlled pilot to a fully connected and data-ready member platform.
>
> The recommended option is the AIRUUN Engagement Platform at THB 2.50 million implementation cost, providing member personalization, event engagement and behavioral analytics.
>
> Including annual maintenance and Webmaster services, the estimated first-year investment is THB 2.95 million, excluding VAT, infrastructure, third-party licenses and content production.
